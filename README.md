# Homebrew-Tap von Flixtake

Programme von [Flixtake](https://flixtake.com) für macOS über Homebrew.

## ClipFix

ClipFix prüft Videoclips auf Fehler im Bildablauf und behebt sie. Für Mac mit Apple-Chip.

```sh
brew install --cask flixtake-it-germany/tap/clipfix
```

Neue Versionen holst du mit `brew upgrade --cask clipfix`. Mehr zu ClipFix: [flixtake.com/clipfix](https://flixtake.com/clipfix)

In diesem Verzeichnis liegen nur die Installationsanleitungen für Homebrew. Die Programme selbst lädt Homebrew signiert und von Apple notarisiert von den Servern von Flixtake.
